# Regresiones en navegador nativo

1. Inicia `npm run dev`.
2. Abre `http://localhost:3000/e2e/native/index.html` en Chrome (ajusta el puerto si corresponde).
3. Pulsa **Ejecutar regresiones**. Debe mostrar **11/11 regresiones correctas**.

La página utiliza las clases y prácticas actuales, `buildPreviewDocument` y `runChallengeValidation`, en iframes nuevos por caso. Incluye programas iniciales, soluciones de sintaxis alternativa y errores de valor inicial, actualización y validez. Un error de ejecución del evaluador nunca cuenta como un rechazo correcto.

Es una prueba de navegador, no forma parte de `npm test`: Happy DOM no implementa `ElementInternals` ni la asociación de custom elements a formularios. No se sustituye esa API por mocks. No requiere backend, sesiones ni audio y no escribe progreso. Vite solo incluye el `index.html` principal en la compilación de producción; esta entrada no se importa desde la aplicación.
