En esta lección no añadiremos sintaxis nueva. Vamos a reunir lo que ya aprendiste para construir una lista de tareas pequeña, paso a paso y sin piezas misteriosas.

El array tareas conserva los datos. El campo recibe el texto, el botón dispara un evento y la lista muestra el resultado. Cada una de estas piezas apareció en una lección anterior.

Dividimos el trabajo entre tres funciones. agregarTarea valida y guarda el texto. dibujarTareas recorre el array y actualiza la lista. manejarClick conecta la entrada de la persona con esas dos tareas.

Hay una distinción importante: la lista visible no es nuestra fuente de datos. Las tareas viven en el array. Cuando ese array cambia, volvemos a dibujar la pantalla para que ambos coincidan.

Tu parte del proyecto se concentra en agregarTarea. La función debe ignorar un texto vacío, guardar un texto válido y devolver la cantidad actual de tareas. Resuelve una regla a la vez.

Terminaste un proyecto que combina varias ideas fundamentales sin saltarse pasos. A continuación aprenderás a investigar errores, comprobar comportamientos y organizar programas cada vez más completos.
