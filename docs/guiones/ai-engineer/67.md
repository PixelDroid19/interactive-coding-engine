La misma representación puede apoyar varias tareas. Búsqueda compara una consulta con documentos. Recomendación compara preferencias con elementos.

Clasificación busca la etiqueta o ejemplo más cercano. Detección de anomalías compara una entrada con una región considerada normal.

Ninguna puntuación decide sola. Cada uso necesita datos de evaluación, umbrales y una salida desconocida.

Clasifica la necesidad. Usa el verbo del producto, no el nombre del modelo.
