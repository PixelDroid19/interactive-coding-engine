---

Ollama y LM Studio ejecutan modelos en tu equipo. Ollama se usa mucho desde terminal y API. LM Studio añade una interfaz para descargar, cargar y servir modelos.

OpenRouter no ejecuta el modelo en tu navegador. Es una API remota que unifica modelos y puede aplicar rutas o fallbacks entre proveedores.

La elección depende de red, hardware, privacidad, interfaz y contrato. Ninguna herramienta elimina la evaluación del modelo.

Elige una plataforma por restricción. No fijes una marca para todos los casos.
