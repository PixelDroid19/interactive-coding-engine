Una aplicación multimodal no es solo adjuntar archivos. Debe indicar qué imagen, región o intervalo de audio sostiene cada resultado.

Normaliza cada modalidad por separado, conserva ids y combina únicamente lo necesario para la tarea.

El ejemplo crea una referencia con modalidad e id.

Completa el contrato y conserva el instante proporcionado.
