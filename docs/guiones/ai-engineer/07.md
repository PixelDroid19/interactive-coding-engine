title: "Inferencia: predecir el siguiente token"
mode: silent
---

El modelo no escribe una frase completa de una vez. Calcula puntuaciones para el siguiente token a partir del contexto visible.

Después una estrategia transforma esas puntuaciones en una elección. Si siempre tomas el máximo, la ejecución es determinista para esa distribución.

El ejemplo recorre un objeto de candidatos y conserva el de mayor probabilidad. Así vemos la decisión sin una red neuronal real.

Completa la selección y no dependas del nombre del token. Las pruebas usarán distribuciones diferentes.
