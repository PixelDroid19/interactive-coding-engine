title: "Construir y conectar MCP local o remoto"
mode: silent
---

Un servidor MCP declara capacidades y responde solicitudes. Un cliente mantiene una conexión. El host decide permisos y qué información llega al modelo.

stdio es común para un proceso local. Streamable HTTP conecta un servicio remoto y necesita autenticación, TLS, límites y manejo de sesión.

Construir un servidor empieza por una capacidad pequeña. Construir el cliente empieza por inicializar, negociar y listar antes de invocar.

Elige el transporte por ubicación. No uses HTTP remoto para simular un proceso local sin necesidad.
