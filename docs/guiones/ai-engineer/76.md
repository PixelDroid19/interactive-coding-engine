Imagen, video y audio no son una sola tarea. Una API de visión analiza o genera imágenes. Video añade orden temporal y marcas de tiempo.

Whisper es un ejemplo de modelo de transcripción. Una API TTS produce voz. Un modelo live gestiona turnos y streaming. Sus contratos no se intercambian.

Las marcas del roadmap, como DALL-E o APIs de Gemini, cambian. Aprende primero la tarea, la entrada y la evidencia esperada.

Elige la operación por modalidad y dirección.
