Cambiar modelo, prompt o índice puede mejorar una métrica y dañar otra. Ejecuta el mismo evalset y aplica guardas.

En producción, un canary limita exposición. Monitorea distribución de entradas, fallos y feedback antes de ampliar.

El ejemplo acepta una versión solo si mantiene calidad y seguridad.

Completa las dos guardas; una mejora de calidad no compra un fallo de seguridad.
