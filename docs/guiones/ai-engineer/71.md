Una implementación manual enseña el bucle y da control. El OpenAI Agents SDK y Claude Agent SDK aportan herramientas, sesiones y coordinación en sus ecosistemas.

Google ADK es un kit de código. Vertex AI Agent Builder añade servicios gestionados de despliegue y gobierno. Son niveles distintos.

Elige manual para un flujo pequeño o para aprender. Usa un SDK cuando sus piezas reducen trabajo. Usa una plataforma si necesitas su operación gestionada.

Clasifica el nivel. No confundas una biblioteca con un servicio desplegado.
