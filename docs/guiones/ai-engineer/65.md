mode: silent

Un asistente de código necesita contexto del repositorio, herramientas limitadas y una definición de terminado.

Leer, editar, ejecutar y revisar son pasos distintos. Un build verde no prueba una experiencia visual; una captura tampoco prueba todos los flujos.

El ejemplo decide si una tarea está lista con implementación y validación.

Completa ambas condiciones. Un cambio sin evidencia sigue incompleto.
