Cuando el historial crece, la aplicación puede descartar, resumir o recuperar. Cada opción pierde información distinta.

Un resumen debe conservar decisiones, hechos vigentes, pendientes y fuentes. También registra hasta qué punto cubre el historial.

El ejemplo conserva los últimos elementos como una compactación determinista pequeña.

Completa la función para cualquier límite. Un límite cero devuelve una lista vacía.
