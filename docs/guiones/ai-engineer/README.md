# Guiones de AI Engineer

Texto hablado solamente. Cada archivo corresponde a una clase y debe coincidir palabra por palabra con el audio que se genere más adelante.

El curso construye un único producto, el TutorLocal: un chat educativo local que crece por capacidades a lo largo de siete fases.

## Fase 1 · Pensamiento y fundamentos

- 01. Nace el chat: entrada, proceso y salida
- 02. Algoritmos y estados: cómo decide el chat
- 03. La lista de mensajes: datos antes que pantallas
- 04. Modelo e inferencia: elegir entre candidatas

## Fase 2 · Conversación con modelos

- 05. Mensajes con roles
- 06. Historial bajo presupuesto
- 07. La instrucción del sistema
- 08. Restricciones que el código puede comprobar
- 09. Temperatura y top-p: controlar la variedad
- 10. Streaming: responder por partes
- 11. Salidas JSON con validación
- 12. Montar la conversación completa

## Fase 3 · Modelo local en el navegador

- 13. WebGPU y Workers: la ruta local
- 14. Descarga, caché y progreso
- 15. Elegir modelo según tu equipo
- 16. La llamada al modelo local

## Fase 4 · Embeddings y búsqueda semántica

- 17. Embeddings: significado convertido en vectores
- 18. Embeddings reales con Transformers.js y WebGPU
- 19. Comparar vectores: producto punto y coseno
- 20. Búsqueda semántica sobre tus notas

## Fase 5 · Documentos y RAG

- 21. Leer documentos con seguridad
- 22. Chunking: dividir el documento
- 23. Fragmentos con identidad
- 24. Recuperar los fragmentos pertinentes
- 25. Presupuesto de contexto
- 26. El modo RAG del chat
- 27. Citas verificables
- 28. Abstenerse cuando falta evidencia

## Fase 6 · Un sistema más confiable

- 29. Memoria de conversación
- 30. Herramientas declaradas
- 31. Confirmación humana en acciones sensibles
- 32. Inyección de prompts: los datos no mandan
- 33. Evaluar las respuestas del chat
- 34. Observabilidad: eventos, errores y latencia
- 35. Caché y rendimiento

## Fase 7 · La aplicación completa

- 36. El mapa completo del chat
- 37. Medir calidad con documentos propios
- 38. Respuestas sin evidencia
- 39. La entrega del TutorLocal
