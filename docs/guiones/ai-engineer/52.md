title: "Prompt injection directa e indirecta"
mode: silent
---

Una inyección directa llega en el mensaje del usuario. Una indirecta puede aparecer dentro de una web, un PDF o el resultado de una herramienta.

Separar instrucciones de datos ayuda, pero no basta. El programa limita herramientas, valida salidas y conserva decisiones sensibles fuera del modelo.

El ejemplo marca como no confiable cualquier bloque externo, aunque parezca una orden del sistema.

Completa la clasificación usando el origen, no palabras mágicas dentro del texto.
