title: "Recursos, prompts, tools y transportes MCP"
mode: silent
---

MCP separa capacidades para que el host pueda presentarlas y autorizarlas de forma distinta.

Los resources representan datos; prompts son plantillas; tools realizan operaciones; el transport mueve mensajes.

La función devuelve el verbo principal de cada capacidad.

Completa los cuatro tipos y usa desconocido para otro valor.
