title: "Evaluaciones deterministas, humanas y con modelos"
mode: silent
---

Un parser, una igualdad o una regla de seguridad se prueban de forma determinista. La utilidad o el tono pueden necesitar una rúbrica humana.

Un modelo evaluador escala comparaciones abiertas, pero tiene sesgo, variación y desacuerdo. Se calibra contra ejemplos humanos.

El ejemplo elige un juez según la propiedad.

Completa el mapa y no uses un modelo para validar un JSON que el programa puede parsear.
