Después de dividir, el pipeline genera embeddings por lote y hace upsert con ids estables.

La versión del modelo viaja en metadatos. Cambiarla crea una reindexación controlada, no una mezcla silenciosa.

El ejemplo crea un id de punto a partir de documento y posición.

Completa el id sin valores fijos. Dos chunks del mismo documento deben ser distintos.
