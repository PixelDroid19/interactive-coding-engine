Guardar solo una lista de números crea un índice que no puede explicar de dónde salió un resultado.

Cada punto necesita id estable, vector, texto o referencia, metadatos y versión del modelo.

El ejemplo construye un registro sin mezclar categoría dentro del vector.

Completa la función con los valores recibidos. La prueba cambiará id, texto y categoría.
