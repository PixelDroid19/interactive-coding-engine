ScopedElementsMixin. ScopedElementsMixin conecta el registro local con el Shadow Root que renderiza Lit.

En ScopedElementsMixin, este archivo es la frontera que vamos a observar. No trabaja solo: La clase compone el mixin una sola vez y entrega clases importadas mediante scopedElements.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped16; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Aplicar el mixin pero olvidar el registro produce etiquetas sin comportamiento; inspecciona primero la clase asociada al nombre local.

Te devuelvo el punto de partida de ScopedElementsMixin. Predice las tres comprobaciones de resolverScoped16 antes de escribir y corrige una sola causa cada vez.

Después del reto de ScopedElementsMixin, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
