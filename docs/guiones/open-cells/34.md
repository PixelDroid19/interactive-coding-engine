Coverage útil por archivo. Coverage señala qué código fue ejecutado; no demuestra por sí solo que el comportamiento sea correcto.

En Coverage útil por archivo, este archivo es la frontera que vamos a observar. No trabaja solo: La interfaz diferencia cobertura de líneas y cobertura de contratos públicos, con archivos y denominadores visibles.

Consulta la parte de la API pública solicitada. La comprobación debe aceptar valores distintos y no depender del orden del objeto. Primero aislamos esa decisión en leerApiPublica34; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: entrada pública → consumidor real → evidencia repetible. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Celebrar 100% con aserciones débiles crea falsa seguridad; introduce un defecto y verifica que al menos una prueba falle.

Te devuelvo el punto de partida de Coverage útil por archivo. Predice las tres comprobaciones de leerApiPublica34 antes de escribir y corrige una sola causa cada vez.

Después del reto de Coverage útil por archivo, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
