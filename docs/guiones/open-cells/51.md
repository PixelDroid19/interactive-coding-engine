Publicar y suscribirse. Un canal es un conducto nombrado con un último valor; publicar cambia ese valor y notifica observadores.

En Publicar y suscribirse, este archivo es la frontera que vamos a observar. No trabaja solo: Productor y suscriptor acuerdan nombre, forma del payload y momento de creación.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal51; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Dos nombres casi iguales crean canales distintos sin error; centraliza contratos y prueba extremo a extremo.

Te devuelvo el punto de partida de Publicar y suscribirse. Predice las tres comprobaciones de elegirCanal51 antes de escribir y corrige una sola causa cada vez.

Después del reto de Publicar y suscribirse, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
