Error recuperable. Un error útil explica qué falló, conserva contexto seguro y ofrece una acción posible como reintentar.

Abrimos app/data/academy-product-data-manager.js. Este archivo posee petición, estados, carreras y cancelación. Observa su entrada y busca qué otro archivo lo consume.

Abrimos package.json. Este archivo declara identidad, entradas, dependencias y comandos que consumen las herramientas. Observa su entrada y busca qué otro archivo lo consume.

Ejecutamos el proyecto después de conectar sus archivos. La evidencia que buscamos es esta: Retry crea una petición nueva, limpia el error anterior y no duplica suscripciones.

Antes de practicar, contrasta el resultado con este error frecuente: Capturar y no emitir el error produce un spinner eterno; fuerza un rechazo y sigue la transición completa.
