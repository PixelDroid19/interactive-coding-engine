static get scopedElements(). scopedElements es una tabla nombre → clase, no una lista de strings ni una segunda importación.

En static get scopedElements(), este archivo es la frontera que vamos a observar. No trabaja solo: Cada etiqueta usada por el template tiene una clase alcanzable y la clave coincide exactamente con el tag renderizado.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped17; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Una diferencia de un guion deja el elemento sin actualizar; compara tag, clave y export de clase como una cadena.

Te devuelvo el punto de partida de static get scopedElements(). Predice las tres comprobaciones de resolverScoped17 antes de escribir y corrige una sola causa cada vez.

Después del reto de static get scopedElements(), la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
