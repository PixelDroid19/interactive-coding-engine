Locales generados y divergencias. La generación ayuda a descubrir claves, pero una persona sigue decidiendo traducción y contexto.

En Locales generados y divergencias, este archivo es la frontera que vamos a observar. No trabaja solo: El comando enumera claves usadas, conserva traducciones existentes y marca faltantes sin inventar frases definitivas.

Consulta la parte de la API pública solicitada. La comprobación debe aceptar valores distintos y no depender del orden del objeto. Primero aislamos esa decisión en leerApiPublica35; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: entrada pública → consumidor real → evidencia repetible. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Sobrescribir catálogos borra trabajo; compara antes y produce un cambio revisable.

Te devuelvo el punto de partida de Locales generados y divergencias. Predice las tres comprobaciones de leerApiPublica35 antes de escribir y corrige una sola causa cada vez.

Después del reto de Locales generados y divergencias, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
