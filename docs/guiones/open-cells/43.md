CellsPageMixin. Una página es un componente enrutable con API de Bridge y ciclo de activación.

En CellsPageMixin, este archivo es la frontera que vamos a observar. No trabaja solo: Su tag y clase terminan en -page, aplica CellsPageMixin y mantiene renderizado declarativo.

Devuelve la ruta cuyo name coincide con la intención recibida. No uses el path como sustituto ni elijas siempre la primera ruta. Primero aislamos esa decisión en resolverRuta43; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: ruta → página activa → entrada y cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Usar el mixin en cada componente borra fronteras; resérvalo para superficies que participan en rutas y canales de app.

Te devuelvo el punto de partida de CellsPageMixin. Predice las tres comprobaciones de resolverRuta43 antes de escribir y corrige una sola causa cada vez.

Después del reto de CellsPageMixin, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
