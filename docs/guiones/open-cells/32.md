Pruebas de comportamiento público. Una buena prueba describe lo que cualquier consumidor puede hacer y observar.

En Pruebas de comportamiento público, este archivo es la frontera que vamos a observar. No trabaja solo: Crea el tag, asigna entradas variadas, espera actualización, interactúa y comprueba DOM o eventos públicos.

Consulta la parte de la API pública solicitada. La comprobación debe aceptar valores distintos y no depender del orden del objeto. Primero aislamos esa decisión en leerApiPublica32; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: entrada pública → consumidor real → evidencia repetible. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Buscar una línea exacta rechaza soluciones equivalentes; prefiere valores diferentes y resultados observables.

Te devuelvo el punto de partida de Pruebas de comportamiento público. Predice las tres comprobaciones de leerApiPublica32 antes de escribir y corrige una sola causa cada vez.

Después del reto de Pruebas de comportamiento público, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
