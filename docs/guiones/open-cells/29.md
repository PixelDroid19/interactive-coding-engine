detail, bubbles y composed. detail transporta el dato; bubbles permite ascender; composed permite cruzar Shadow DOM. Cada opción responde una frontera.

En detail, bubbles y composed, este archivo es la frontera que vamos a observar. No trabaja solo: El consumidor escucha en una superficie estable y recibe solo la información necesaria para reaccionar.

Busca la clave en el idioma solicitado y sustituye los placeholders recibidos. Una clave ausente debe seguir siendo visible como ausencia. Primero aislamos esa decisión en crearMensaje29; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: clave y valores → texto localizado; acción → evento público. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Enviar la instancia completa en detail filtra estado privado; reconstruye un payload explícito con valores serializables.

Te devuelvo el punto de partida de detail, bubbles y composed. Predice las tres comprobaciones de crearMensaje29 antes de escribir y corrige una sola causa cada vez.

Después del reto de detail, bubbles y composed, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
