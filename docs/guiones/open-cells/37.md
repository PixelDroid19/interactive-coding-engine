Build de demo y resolución de módulos. Construir es resolver un grafo desde entradas concretas y producir artefactos ejecutables, no concatenar archivos al azar.

En Build de demo y resolución de módulos, este archivo es la frontera que vamos a observar. No trabaja solo: Imports locales y permitidos se resuelven, rutas inválidas fallan y la demo ejecuta el mismo módulo que se exporta.

Consulta la parte de la API pública solicitada. La comprobación debe aceptar valores distintos y no depender del orden del objeto. Primero aislamos esa decisión en leerApiPublica37; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: entrada pública → consumidor real → evidencia repetible. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Un preview en blanco sin canal de errores deja al estudiante adivinando; comunica fallo, archivo y causa al host.

Te devuelvo el punto de partida de Build de demo y resolución de módulos. Predice las tres comprobaciones de leerApiPublica37 antes de escribir y corrige una sola causa cada vez.

Después del reto de Build de demo y resolución de módulos, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
