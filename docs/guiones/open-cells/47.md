Definir rutas y nombres. path pertenece a la URL; name es el identificador estable que usa navigate; component es el tag que se renderiza.

En Definir rutas y nombres, este archivo es la frontera que vamos a observar. No trabaja solo: Cada ruta tiene las tres piezas coherentes y solo una ruta notFound.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal47; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Navegar usando el path donde la API espera name rompe alias y cambios futuros; prueba un path alternativo para la misma página.

Te devuelvo el punto de partida de Definir rutas y nombres. Predice las tres comprobaciones de elegirCanal47 antes de escribir y corrige una sola causa cada vez.

Después del reto de Definir rutas y nombres, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
