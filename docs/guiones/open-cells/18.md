Importar clases sin registro global. Importar una clase obtiene su implementación; registrarla decide dónde puede resolverla el navegador. Son operaciones diferentes.

En Importar clases sin registro global, este archivo es la frontera que vamos a observar. No trabaja solo: Los módulos de dependencias exportan clases consumibles y evitan efectos globales innecesarios.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped18; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Confundir import con registro oculta por qué una etiqueta no funciona; busca explícitamente quién posee el registro.

Te devuelvo el punto de partida de Importar clases sin registro global. Predice las tres comprobaciones de resolverScoped18 antes de escribir y corrige una sola causa cada vez.

Después del reto de Importar clases sin registro global, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
