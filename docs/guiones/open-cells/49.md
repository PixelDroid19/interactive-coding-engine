Parámetros de ruta. Los parámetros son entrada de la visita, no estado global permanente.

En Parámetros de ruta, este archivo es la frontera que vamos a observar. No trabaja solo: La ruta identifica campos, navigate los entrega y onPageEnter valida ausencia, tipo y valor.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal49; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Confiar en que id siempre existe crea pantallas vacías; ensaya navegación sin id y una ruta desconocida.

Te devuelvo el punto de partida de Parámetros de ruta. Predice las tres comprobaciones de elegirCanal49 antes de escribir y corrige una sola causa cada vez.

Después del reto de Parámetros de ruta, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
