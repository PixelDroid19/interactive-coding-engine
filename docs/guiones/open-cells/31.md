Demo interactiva del componente. La demo es el consumidor humano más pequeño: configura entradas, escucha salidas y muestra estados importantes.

En Demo interactiva del componente, este archivo es la frontera que vamos a observar. No trabaja solo: Puede probar propiedades, eventos y variantes sin editar el módulo del componente.

Consulta la parte de la API pública solicitada. La comprobación debe aceptar valores distintos y no depender del orden del objeto. Primero aislamos esa decisión en leerApiPublica31; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: entrada pública → consumidor real → evidencia repetible. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Una demo que replica lógica interna puede verse bien cuando el paquete está roto; importa siempre la entrada pública.

Te devuelvo el punto de partida de Demo interactiva del componente. Predice las tres comprobaciones de leerApiPublica31 antes de escribir y corrige una sola causa cada vez.

Después del reto de Demo interactiva del componente, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
