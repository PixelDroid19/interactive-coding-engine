Busca la clave en el idioma solicitado y sustituye los placeholders recibidos. Una clave ausente debe seguir siendo visible como ausencia. Primero aislamos esa decisión en crearMensaje27; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: clave y valores → texto localizado; acción → evento público. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Un setTimeout largo solo esconde carreras; reemplázalo por la condición observable que necesitas.
