Para entender Analítica con contratos de eventos, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

El siguiente enlace aparece en app/scripts/app-routes.js. Este archivo relaciona URL, nombre estable, tag de página y carga lazy. Revisa qué recibe de app/analytics/events.js y qué deja preparado para app/components/academy-product-card/academy-product-card.js. app/scripts/app-routes.js actúa como consumidor del cambio y no necesita otra edición en este paso.

Ahora pasamos a app/components/academy-product-card/academy-product-card.js. Este archivo encapsula presentación y devuelve una intención mediante evento.
