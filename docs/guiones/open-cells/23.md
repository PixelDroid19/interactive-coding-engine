this.t y claves visibles. La interfaz pide significado mediante una clave; el catálogo decide la frase para el idioma activo.

En this.t y claves visibles, este archivo es la frontera que vamos a observar. No trabaja solo: Todo texto de producto usa claves estables, y una clave ausente se ve como error en vez de desaparecer.

Busca la clave en el idioma solicitado y sustituye los placeholders recibidos. Una clave ausente debe seguir siendo visible como ausencia. Primero aislamos esa decisión en crearMensaje23; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: clave y valores → texto localizado; acción → evento público. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Mezclar texto literal y traducido crea pantallas parcialmente localizadas; busca nodos visibles fuera de this.t.

Te devuelvo el punto de partida de this.t y claves visibles. Predice las tres comprobaciones de crearMensaje23 antes de escribir y corrige una sola causa cada vez.

Después del reto de this.t y claves visibles, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
