Placeholders como contrato. Un placeholder es un parámetro de la frase; su nombre también forma parte de la API de traducción.

En Placeholders como contrato, este archivo es la frontera que vamos a observar. No trabaja solo: Cada idioma conserva los mismos placeholders y this.t entrega todos los valores requeridos.

Busca la clave en el idioma solicitado y sustituye los placeholders recibidos. Una clave ausente debe seguir siendo visible como ausencia. Primero aislamos esa decisión en crearMensaje25; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: clave y valores → texto localizado; acción → evento público. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Traducir ${name} como ${nombre} rompe sustitución aunque la frase se entienda; compara nombres dentro de cada valor.

Te devuelvo el punto de partida de Placeholders como contrato. Predice las tres comprobaciones de crearMensaje25 antes de escribir y corrige una sola causa cada vez.

Después del reto de Placeholders como contrato, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
