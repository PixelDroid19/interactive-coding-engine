Placeholders como contrato. Un placeholder es un parámetro de la frase; su nombre también forma parte de la API de traducción. Hoy seguiremos el recorrido locales/locales.json → src/academy-user-summary.js → demo/demo.js → test/unit/academy-user-summary.test.js. Para entender Placeholders como contrato, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

Nuestro punto de partida es locales/locales.json. Este archivo es la fuente de las traducciones del componente. Antes de tocarlo en Placeholders como contrato, localiza su salida pública y predice quién dependerá de ella.

Ahora sí editamos locales/locales.json. En y es repiten exactamente las mismas claves. El placeholder de nombre también debe coincidir para que this.t pueda sustituirlo sin casos especiales. Después lo contrastaremos con src/academy-user-summary.js para verificar el contrato desde otro archivo.

El siguiente enlace aparece en src/academy-user-summary.js. Este archivo implementa la API, el render, las dependencias y el evento del artefacto protagonista. Revisa qué recibe de locales/locales.json y qué deja preparado para demo/demo.js. Solo inspeccionamos src/academy-user-summary.js; cambiarlo también ocultaría la causa del resultado.

Ahora pasamos a demo/demo.js. Este archivo consume la entrada pública y conecta propiedades, idioma y eventos. Revisa qué recibe de src/academy-user-summary.js y qué deja preparado para test/unit/academy-user-summary.test.js. En Placeholders como contrato, demo/demo.js queda intacto para comprobar el contrato desde fuera.

La última parada es test/unit/academy-user-summary.test.js. Este archivo conecta esta responsabilidad con el resto del proyecto. Compáralo con demo/demo.js: deben colaborar sin duplicar responsabilidades. test/unit/academy-user-summary.test.js actúa como consumidor del cambio y no necesita otra edición en este paso.

Ya está conectado el recorrido. La comprobación importante es esta: Cada idioma conserva los mismos placeholders y this.t entrega todos los valores requeridos. Si el preview contradice tu predicción sobre Placeholders como contrato, vuelve al último archivo editado y sigue su salida hasta el consumidor.

Ahora piensa en el caso que suele romper este contrato: Traducir ${name} como ${nombre} rompe sustitución aunque la frase se entienda; compara nombres dentro de cada valor. En Placeholders como contrato, propón una causa, cambia una sola frontera y usa el preview o las pruebas para refutarla.

A continuación podrás repasar el modelo con calma sobre Placeholders como contrato. Después, el proyecto de Placeholders como contrato se abrirá completo para que experimentes y compares soluciones equivalentes sin recibir una línea para copiar.
