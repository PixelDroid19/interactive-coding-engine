Seguridad de iframe, Worker e imports. Código editable vive detrás de fronteras: Worker para transformación y tests; iframe sandbox para UI; allowlist para paquetes.

En Seguridad de iframe, Worker e imports, este archivo es la frontera que vamos a observar. No trabaja solo: No hay acceso a fs, procesos, sockets ni origen del host, y los errores cruzan por mensajes validados.

Valida una entrega completa: ZIP estándar, pruebas, build y ausencia de secretos. Un archivo descargado por sí solo no basta. Primero aislamos esa decisión en validarEntrega66; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: workspace limpio → test y build → ZIP → continuación con CLI. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Añadir allow-same-origin junto con allow-scripts debilita el sandbox; revisa permisos como una lista mínima.

Te devuelvo el punto de partida de Seguridad de iframe, Worker e imports. Predice las tres comprobaciones de validarEntrega66 antes de escribir y corrige una sola causa cada vez.

Después del reto de Seguridad de iframe, Worker e imports, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
