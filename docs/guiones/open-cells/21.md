Import permitido frente a import arbitrario. El runtime browser usa una allowlist porque ejecutar un import equivale a conceder código y red a ese módulo.

En Import permitido frente a import arbitrario, este archivo es la frontera que vamos a observar. No trabaja solo: Solo paquetes previstos, versiones fijadas y módulos locales normalizados entran al preview; lo demás falla con diagnóstico.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped21; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Aceptar cualquier URL hace irreproducible y riesgosa la práctica; prueba un paquete desconocido y exige un rechazo visible.

Te devuelvo el punto de partida de Import permitido frente a import arbitrario. Predice las tres comprobaciones de resolverScoped21 antes de escribir y corrige una sola causa cada vez.

Después del reto de Import permitido frente a import arbitrario, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
