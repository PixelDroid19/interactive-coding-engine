Bootstrap del runtime público. El bootstrap recibe outlet, rutas e inicio; su trabajo es coordinar, no definir contenido de cada página. Hoy seguiremos el recorrido index.html → app/scripts/app.js → app/scripts/app-routes.js → app/pages/academy-home-page/academy-home-page.js. Para entender Bootstrap del runtime público, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

Empezamos por index.html. Este archivo crea la raíz que el runtime montará en el navegador. Antes de tocarlo en Bootstrap del runtime público, localiza su salida pública y predice quién dependerá de ella. En Bootstrap del runtime público, index.html queda intacto para comprobar el contrato desde fuera.

Ahora pasamos a app/scripts/app.js. Este archivo arranca una única instancia del runtime con outlet, rutas e inicio. Revisa qué recibe de index.html y qué deja preparado para app/scripts/app-routes.js.

Aquí hacemos el cambio principal en app/scripts/app.js. Importamos startApp y ROUTES. mainNode coincide con el outlet HTML, initialTemplate coincide con el name de una ruta y el bootstrap ocurre una sola vez. Después lo contrastaremos con app/scripts/app-routes.js para verificar el contrato desde otro archivo.

Después abrimos app/scripts/app-routes.js. Este archivo relaciona URL, nombre estable, tag de página y carga lazy. Revisa qué recibe de app/scripts/app.js y qué deja preparado para app/pages/academy-home-page/academy-home-page.js. Solo inspeccionamos app/scripts/app-routes.js; cambiarlo también ocultaría la causa del resultado.

Terminamos en app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Compáralo con app/scripts/app-routes.js: deben colaborar sin duplicar responsabilidades. En Bootstrap del runtime público, app/pages/academy-home-page/academy-home-page.js queda intacto para comprobar el contrato desde fuera.

Ejecutamos el proyecto y buscamos una señal concreta: Arranca una vez, publica contexto de aplicación y muestra un error observable si falta raíz o ruta inicial. Si el preview contradice tu predicción sobre Bootstrap del runtime público, vuelve al último archivo editado y sigue su salida hasta el consumidor.
