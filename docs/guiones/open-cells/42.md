Bootstrap del runtime público. El bootstrap recibe outlet, rutas e inicio; su trabajo es coordinar, no definir contenido de cada página. Hoy seguiremos el recorrido app/pages/academy-home-page/academy-home-page.js → index.html → app/scripts/app.js → app/scripts/app-routes.js. Empezamos por app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Antes de tocarlo en Bootstrap del runtime público, localiza su salida pública y predice quién dependerá de ella.

Este es el archivo que modificaremos: app/pages/academy-home-page/academy-home-page.js. PageMixin aporta navegación y canales; ScopedElementsMixin resuelve la tarjeta. onPageEnter adquiere recursos, onPageLeave los libera y render conserva UI declarativa.
