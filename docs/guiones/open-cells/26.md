Inicialización y cambio de idioma. El idioma es estado de aplicación que debe estar listo antes de afirmar qué texto ve la persona.

En Inicialización y cambio de idioma, este archivo es la frontera que vamos a observar. No trabaja solo: El shell publica el cambio, los recursos terminan de cargar y los componentes actualizan sin recrear toda la app.

Busca la clave en el idioma solicitado y sustituye los placeholders recibidos. Una clave ausente debe seguir siendo visible como ausencia. Primero aislamos esa decisión en crearMensaje26; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: clave y valores → texto localizado; acción → evento público. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Afirmar inmediatamente después de cambiar idioma produce tests intermitentes; espera la señal de recursos listos.

Te devuelvo el punto de partida de Inicialización y cambio de idioma. Predice las tres comprobaciones de crearMensaje26 antes de escribir y corrige una sola causa cada vez.

Después del reto de Inicialización y cambio de idioma, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
