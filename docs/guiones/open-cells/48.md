Navegación imperativa. navigate expresa una intención desde una página o Bridge; no debe filtrarse hacia componentes puramente visuales. Hoy seguiremos el recorrido app/pages/academy-product-detail-page/academy-product-detail-page.js → app/components/academy-product-card/academy-product-card.js → app/pages/academy-home-page/academy-home-page.js → app/scripts/app-routes.js. Para entender Navegación imperativa, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

Empezamos por app/pages/academy-product-detail-page/academy-product-detail-page.js. Este archivo recibe parámetros de una visita y renderiza el detalle. Antes de tocarlo en Navegación imperativa, localiza su salida pública y predice quién dependerá de ella.

Vamos a completar app/pages/academy-product-detail-page/academy-product-detail-page.js. OnPageEnter recibe params de la navegación y los convierte en estado de la visita; el botón vuelve usando el name home, no una URL copiada. Después lo contrastaremos con app/components/academy-product-card/academy-product-card.js para verificar el contrato desde otro archivo.

Seguimos en app/components/academy-product-card/academy-product-card.js. Este archivo encapsula presentación y devuelve una intención mediante evento. Revisa qué recibe de app/pages/academy-product-detail-page/academy-product-detail-page.js y qué deja preparado para app/pages/academy-home-page/academy-home-page.js. app/components/academy-product-card/academy-product-card.js actúa como consumidor del cambio y no necesita otra edición en este paso.

El siguiente enlace aparece en app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Revisa qué recibe de app/components/academy-product-card/academy-product-card.js y qué deja preparado para app/scripts/app-routes.js. Solo inspeccionamos app/pages/academy-home-page/academy-home-page.js; cambiarlo también ocultaría la causa del resultado.

Terminamos en app/scripts/app-routes.js. Este archivo relaciona URL, nombre estable, tag de página y carga lazy. Compáralo con app/pages/academy-home-page/academy-home-page.js: deben colaborar sin duplicar responsabilidades. En Navegación imperativa, app/scripts/app-routes.js queda intacto para comprobar el contrato desde fuera.

Ejecutamos el proyecto y buscamos una señal concreta: La página traduce el evento del hijo a navigate con un nombre conocido y parámetros explícitos. Si el preview contradice tu predicción sobre Navegación imperativa, vuelve al último archivo editado y sigue su salida hasta el consumidor.

Antes del ejercicio, intenta explicar este fallo: Una tarjeta que importa el router deja de ser reutilizable; muévela a otra página y comprueba que aún funciona. En Navegación imperativa, propón una causa, cambia una sola frontera y usa el preview o las pruebas para refutarla.

La lectura siguiente organiza lo que acabamos de ver sobre Navegación imperativa. Después, el proyecto de Navegación imperativa se abrirá completo para que experimentes y compares soluciones equivalentes sin recibir una línea para copiar.
