Navegación imperativa. navigate expresa una intención desde una página o Bridge; no debe filtrarse hacia componentes puramente visuales.

En Navegación imperativa, este archivo es la frontera que vamos a observar. No trabaja solo: La página traduce el evento del hijo a navigate con un nombre conocido y parámetros explícitos.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal48; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Una tarjeta que importa el router deja de ser reutilizable; muévela a otra página y comprueba que aún funciona.

Te devuelvo el punto de partida de Navegación imperativa. Predice las tres comprobaciones de elegirCanal48 antes de escribir y corrige una sola causa cada vez.

Después del reto de Navegación imperativa, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
