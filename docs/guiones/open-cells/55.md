Cells Bridge como mediador. Bridge conecta páginas y aplicación mediante contratos sin hacer que cada componente conozca a todos los demás.

En Cells Bridge como mediador, este archivo es la frontera que vamos a observar. No trabaja solo: publish, subscribe, navigate y contexto están disponibles solo donde la arquitectura los necesita.

Acepta datos únicamente cuando pertenecen a la solicitud vigente. Una respuesta antigua debe quedar sin publicar. Primero aislamos esa decisión en aceptarRespuesta55; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: petición → estado → respuesta vigente o descarte → cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Convertir Bridge en un contenedor de cualquier variable recrea un estado global opaco; asigna propietario y duración.

Te devuelvo el punto de partida de Cells Bridge como mediador. Predice las tres comprobaciones de aceptarRespuesta55 antes de escribir y corrige una sola causa cada vez.

Después del reto de Cells Bridge como mediador, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
