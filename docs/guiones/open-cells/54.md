Desuscripción y ausencia posterior. Cleanup se demuestra por lo que deja de ocurrir: ninguna entrega después de abandonar la página.

Abrimos app/scripts/channels.js. Este archivo nombra contratos de comunicación de larga distancia. Observa su entrada y busca qué otro archivo lo consume.

Abrimos app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos app/pages/academy-home-page/academy-home-page.js: PageMixin aporta navegación y canales; ScopedElementsMixin resuelve la tarjeta. onPageEnter adquiere recursos, onPageLeave los libera y render conserva UI declarativa.

Abrimos app/pages/academy-product-detail-page/academy-product-detail-page.js. Este archivo recibe parámetros de una visita y renderiza el detalle. Observa su entrada y busca qué otro archivo lo consume.

Abrimos package.json. Este archivo declara identidad, entradas, dependencias y comandos que consumen las herramientas. Observa su entrada y busca qué otro archivo lo consume.

Ejecutamos el proyecto después de conectar sus archivos. La evidencia que buscamos es esta: unsubscribe corta callbacks del host sin borrar el canal para consumidores válidos.

Antes de practicar, contrasta el resultado con este error frecuente: Comprobar solo que se llamó unsubscribe no demuestra efecto; publica después y observa el contador del callback.
