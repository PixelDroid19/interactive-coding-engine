Desuscripción y ausencia posterior. Cleanup se demuestra por lo que deja de ocurrir: ninguna entrega después de abandonar la página.

En Desuscripción y ausencia posterior, este archivo es la frontera que vamos a observar. No trabaja solo: unsubscribe corta callbacks del host sin borrar el canal para consumidores válidos.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal54; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Comprobar solo que se llamó unsubscribe no demuestra efecto; publica después y observa el contador del callback.

Te devuelvo el punto de partida de Desuscripción y ausencia posterior. Predice las tres comprobaciones de elegirCanal54 antes de escribir y corrige una sola causa cada vez.

Después del reto de Desuscripción y ausencia posterior, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
