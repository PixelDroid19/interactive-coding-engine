Páginas declarativas y lazy. La tabla de rutas describe qué página corresponde a cada nombre y cómo cargarla cuando se necesita.

En Páginas declarativas y lazy, este archivo es la frontera que vamos a observar. No trabaja solo: Cada action devuelve un import dinámico y el componente declarado coincide con el tag definido por el módulo.

Devuelve la ruta cuyo name coincide con la intención recibida. No uses el path como sustituto ni elijas siempre la primera ruta. Primero aislamos esa decisión en resolverRuta44; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: ruta → página activa → entrada y cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Importar todas las páginas al inicio contradice lazy loading; observa la red antes y después de navegar.

Te devuelvo el punto de partida de Páginas declarativas y lazy. Predice las tres comprobaciones de resolverRuta44 antes de escribir y corrige una sola causa cada vez.

Después del reto de Páginas declarativas y lazy, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
