Workspace real de aplicación. El workspace es un proyecto exportable y versionado, no una colección de snippets sin relación.

En Workspace real de aplicación, este archivo es la frontera que vamos a observar. No trabaja solo: La entrada, rutas y páginas forman un grafo resoluble; dev y prod conservan configuración explícita.

Devuelve la ruta cuyo name coincide con la intención recibida. No uses el path como sustituto ni elijas siempre la primera ruta. Primero aislamos esa decisión en resolverRuta40; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: ruta → página activa → entrada y cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Guardar solo el archivo activo produce un ZIP incompleto; valida el snapshot entero antes de construir.

Te devuelvo el punto de partida de Workspace real de aplicación. Predice las tres comprobaciones de resolverRuta40 antes de escribir y corrige una sola causa cada vez.

Después del reto de Workspace real de aplicación, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
