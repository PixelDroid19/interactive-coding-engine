Data manager separado. El data manager posee transporte, cancelación y transformación; la página posee presentación y navegación. Hoy seguiremos el recorrido app/pages/academy-search-page/academy-search-page.js → app/components/academy-product-card/academy-product-card.js → app/pages/academy-home-page/academy-home-page.js → app/scripts/channels.js. Para entender Data manager separado, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

Empezamos por app/pages/academy-search-page/academy-search-page.js. Este archivo posee la consulta y deriva resultados sin mutar el catálogo original. Antes de tocarlo en Data manager separado, localiza su salida pública y predice quién dependerá de ella.

Ahora sí editamos app/pages/academy-search-page/academy-search-page.js. Query cambia con el input y results se deriva en cada render; la misma tarjeta reutilizable presenta cada coincidencia. Después lo contrastaremos con app/components/academy-product-card/academy-product-card.js para verificar el contrato desde otro archivo.

El siguiente enlace aparece en app/components/academy-product-card/academy-product-card.js. Este archivo encapsula presentación y devuelve una intención mediante evento. Revisa qué recibe de app/pages/academy-search-page/academy-search-page.js y qué deja preparado para app/pages/academy-home-page/academy-home-page.js. app/components/academy-product-card/academy-product-card.js actúa como consumidor del cambio y no necesita otra edición en este paso.

Ahora pasamos a app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Revisa qué recibe de app/components/academy-product-card/academy-product-card.js y qué deja preparado para app/scripts/channels.js. Solo inspeccionamos app/pages/academy-home-page/academy-home-page.js; cambiarlo también ocultaría la causa del resultado.

Terminamos en app/scripts/channels.js. Este archivo nombra contratos de comunicación de larga distancia. Compáralo con app/pages/academy-home-page/academy-home-page.js: deben colaborar sin duplicar responsabilidades. En Data manager separado, app/scripts/channels.js queda intacto para comprobar el contrato desde fuera.

Ejecutamos el proyecto y buscamos una señal concreta: La página observa estados públicos del manager sin construir URLs ni interpretar respuestas crudas. Si el preview contradice tu predicción sobre Data manager separado, vuelve al último archivo editado y sigue su salida hasta el consumidor.

Antes del ejercicio, intenta explicar este fallo: Un manager que navega o pinta DOM mezcla capas; reemplaza la página por una prueba y verifica que sigue usable. En Data manager separado, propón una causa, cambia una sola frontera y usa el preview o las pruebas para refutarla.
