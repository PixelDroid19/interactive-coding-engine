Dos hosts y una misma etiqueta. El aislamiento se demuestra cuando dos hosts resuelven la misma etiqueta a implementaciones distintas sin interferirse.

En Dos hosts y una misma etiqueta, este archivo es la frontera que vamos a observar. No trabaja solo: Cada host renderiza su versión, actualiza de forma independiente y no modifica customElements global.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped19; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Probar un solo host no demuestra aislamiento; monta ambos simultáneamente y compara constructor y salida.

Te devuelvo el punto de partida de Dos hosts y una misma etiqueta. Predice las tres comprobaciones de resolverScoped19 antes de escribir y corrige una sola causa cada vez.

Después del reto de Dos hosts y una misma etiqueta, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
