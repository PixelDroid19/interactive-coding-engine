Crear una app Cells. Una app Cells coordina páginas, rutas, canales, configuración y servicios; no es un componente enorme con muchos if.

En Crear una app Cells, este archivo es la frontera que vamos a observar. No trabaja solo: El scaffold separa app/scripts, pages, components, data, config, locales y tests con una entrada ejecutable.

Devuelve la ruta cuyo name coincide con la intención recibida. No uses el path como sustituto ni elijas siempre la primera ruta. Primero aislamos esa decisión en resolverRuta39; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: ruta → página activa → entrada y cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Comenzar copiando una app completa oculta responsabilidades; recorre primero quién importa y quién llama cada pieza.

Te devuelvo el punto de partida de Crear una app Cells. Predice las tres comprobaciones de resolverRuta39 antes de escribir y corrige una sola causa cada vez.

Después del reto de Crear una app Cells, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
