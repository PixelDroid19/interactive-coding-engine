Crear una app Cells. Una app Cells coordina páginas, rutas, canales, configuración y servicios; no es un componente enorme con muchos if.

Abrimos package.json. Este archivo declara identidad, entradas, dependencias y comandos que consumen las herramientas. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos package.json: type module permite usar import y export. exports señala la entrada pública; cells.entry señala el bootstrap de una app. Los scripts nombran operaciones reales de desarrollo, pruebas, locales y build.

Abrimos index.html. Este archivo crea la raíz que el runtime montará en el navegador. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos index.html: el main con id app es el outlet. El script type module carga app/scripts/app.js; el nombre del id debe coincidir después con mainNode.

Abrimos app/scripts/app.js. Este archivo arranca una única instancia del runtime con outlet, rutas e inicio. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos app/scripts/app.js: importamos startApp y ROUTES. mainNode coincide con el outlet HTML, initialTemplate coincide con el name de una ruta y el bootstrap ocurre una sola vez.

Abrimos app/scripts/app-routes.js. Este archivo relaciona URL, nombre estable, tag de página y carga lazy. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos app/scripts/app-routes.js: cada objeto separa path de URL, name estable, component que se monta y action que importa la página solo cuando se visita.

Abrimos app/pages/academy-home-page/academy-home-page.js. Este archivo coordina componentes, ciclo de página y navegación. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos app/pages/academy-home-page/academy-home-page.js: PageMixin aporta navegación y canales; ScopedElementsMixin resuelve la tarjeta. onPageEnter adquiere recursos, onPageLeave los libera y render conserva UI declarativa.

Ejecutamos el proyecto después de conectar sus archivos. La evidencia que buscamos es esta: El scaffold separa app/scripts, pages, components, data, config y tests. Los textos globales viven en app/locales-app y los propios de una página dentro de la carpeta de esa página.

Antes de practicar, contrasta el resultado con este error frecuente: Comenzar copiando una app completa oculta responsabilidades; recorre primero quién importa y quién llama cada pieza.
