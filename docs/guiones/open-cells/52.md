Payloads estables. El payload de canal es una API entre partes que pueden evolucionar por separado.

En Payloads estables, este archivo es la frontera que vamos a observar. No trabaja solo: Contiene datos serializables, versión o forma documentada y evita instancias privadas.

Elige evento para un árbol cercano, canal para participantes lejanos y navegación cuando la intención cambia de página. Primero aislamos esa decisión en elegirCanal52; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: intención → evento, canal o navegación → consumidor. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Enviar un elemento DOM permite mutaciones invisibles; copia los valores de negocio que realmente necesita el receptor.

Te devuelvo el punto de partida de Payloads estables. Predice las tres comprobaciones de elegirCanal52 antes de escribir y corrige una sola causa cada vez.

Después del reto de Payloads estables, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
