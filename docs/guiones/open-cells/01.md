Qué añade Cells sobre Lit. Sitúa Cells como una arquitectura de aplicaciones y componentes que se apoya en Lit sin sustituir sus fundamentos.

Abrimos package.json. Este archivo declara identidad, entradas, dependencias y comandos que consumen las herramientas. Observa su entrada y busca qué otro archivo lo consume.

Ahora construimos package.json: type module permite usar import y export. exports señala la entrada pública; cells.entry señala el bootstrap de una app. Los scripts nombran operaciones reales de desarrollo, pruebas, locales y build.

Abrimos index.js. Este archivo expone la clase sin registrar efectos globales. Observa su entrada y busca qué otro archivo lo consume.

Abrimos src/academy-learning-card.js. Este archivo implementa propiedades, render, dependencias scoped y eventos del componente. Observa su entrada y busca qué otro archivo lo consume.

Abrimos demo/index.html. Este archivo presenta controles y una instancia real del paquete. Observa su entrada y busca qué otro archivo lo consume.

Ejecutamos el proyecto después de conectar sus archivos. La evidencia que buscamos es esta: Un componente encapsula una responsabilidad visual reutilizable. Una página participa en navegación y ciclo de entrada o salida. Una aplicación compone páginas, rutas, canales, configuración y servicios. Elegir la frontera correcta evita componentes gigantes que conocen toda la aplicación.

Antes de practicar, contrasta el resultado con este error frecuente: Cada práctica modifica un workspace exportable. El navegador sustituye únicamente las capacidades de proceso que no existen en la web; los archivos, nombres, imports y contratos públicos continúan siendo compatibles con un proyecto Cells. Un error frecuente consiste en cambiar varias fronteras a la vez; conserva una predicción y comprueba una sola causa antes de continuar.

La lectura siguiente abre un laboratorio de proyecto para Qué añade Cells sobre Lit. Allí corregirás archivos reales, construirás la vista previa y ejecutarás contratos sin recibir una solución copiada.
