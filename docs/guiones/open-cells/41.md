Configuración dev y prod. Configuración cambia valores de entorno; no debe cambiar las reglas de negocio ni exigir editar fuentes.

En Configuración dev y prod, este archivo es la frontera que vamos a observar. No trabaja solo: Cada entorno declara API, logging y flags esperados, y producción no hereda opciones de depuración.

Devuelve la ruta cuyo name coincide con la intención recibida. No uses el path como sustituto ni elijas siempre la primera ruta. Primero aislamos esa decisión en resolverRuta41; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: ruta → página activa → entrada y cleanup. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Leer process.env dentro del navegador falla o se reemplaza tarde; importa una configuración generada y verificable.

Te devuelvo el punto de partida de Configuración dev y prod. Predice las tres comprobaciones de resolverRuta41 antes de escribir y corrige una sola causa cada vez.

Después del reto de Configuración dev y prod, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
