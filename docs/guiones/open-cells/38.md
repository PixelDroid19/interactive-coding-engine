Exportar un componente consumible. La exportación es exitosa cuando otro proyecto puede instalar, importar y usar el paquete sin conocer el curso. Hoy seguiremos el recorrido package.json → index.js → custom-elements.json → README.md. Para entender Exportar un componente consumible, identificaremos quién posee cada dato, quién consume su salida y qué resultado observable confirma el contrato.

La primera parada está en package.json. Este archivo declara identidad, entradas, dependencias y comandos que consumen las herramientas. Antes de tocarlo en Exportar un componente consumible, localiza su salida pública y predice quién dependerá de ella.

Este es el archivo que modificaremos: package.json. Type module permite usar import y export. exports señala la entrada pública; cells.entry señala el bootstrap de una app. Los scripts nombran operaciones reales de desarrollo, pruebas, locales y build. Después lo contrastaremos con index.js para verificar el contrato desde otro archivo.
