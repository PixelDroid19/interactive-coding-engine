Grafo de dependencias alcanzables. Un paquete debe declarar lo que importa directamente; el bundler calcula el grafo transitivo desde esas entradas.

En Grafo de dependencias alcanzables, este archivo es la frontera que vamos a observar. No trabaja solo: package.json contiene dependencias directas mínimas y toda importación de producción se puede resolver desde ellas.

Resuelve la clase asociada al tag recibido. No fijes un componente concreto ni registres nada globalmente. Primero aislamos esa decisión en resolverScoped20; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: tag local → registro del host → clase importada. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Añadir el catálogo entero enmascara imports accidentales; elimina una dependencia no usada y vuelve a construir demo y tests.

Te devuelvo el punto de partida de Grafo de dependencias alcanzables. Predice las tres comprobaciones de resolverScoped20 antes de escribir y corrige una sola causa cada vez.

Después del reto de Grafo de dependencias alcanzables, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
