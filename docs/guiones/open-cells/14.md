SCSS fuente y CSS consumible. SCSS es material de autor; el navegador y el paquete consumen CSS. Ambos artefactos deben corresponder a la misma versión.

En SCSS fuente y CSS consumible, este archivo es la frontera que vamos a observar. No trabaja solo: El build produce CSS determinista desde la fuente y el paquete exporta el artefacto que realmente usa la demo.

Haz que el contrato visible respete disabled y conserve loading, empty, error o success. Una entrada desconocida debe producir un estado seguro. Primero aislamos esa decisión en estadoVisible14; después cambiaremos varias entradas para comprobar que no depende de un ejemplo fijo.

La demostración hace visible este modelo: propiedad pública → estado interno → render e interacción. Sigue la entrada que cambia y localiza el caso que debe permanecer ausente, bloqueado o rechazado.

Ahora contrasta el resultado con el error frecuente. Editar solo el CSS generado pierde el cambio al recompilar; identifica siempre cuál archivo es fuente de verdad.

Te devuelvo el punto de partida de SCSS fuente y CSS consumible. Predice las tres comprobaciones de estadoVisible14 antes de escribir y corrige una sola causa cada vez.

Después del reto de SCSS fuente y CSS consumible, la lectura ampliará el porqué, el razonamiento reconstruirá el flujo y la depuración te pedirá transferirlo a otro programa.
