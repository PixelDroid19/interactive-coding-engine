Modela todos los estados de una operación asíncrona y cancela resultados que ya no pertenecen a la consulta actual. En esta clase construiremos un buscador con carga, vacío, error y carreras controladas; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

Una promesa no es una pantalla: el componente traduce el tiempo en estados observables y protege la vista contra respuestas atrasadas.

Fíjate en la frontera, no solo en la sintaxis. Mientras construimos un buscador con carga, vacío, error y carreras controladas, separa responsabilidades de plataforma, componente y consumidor.

Úsalo en búsqueda, carga remota, validación de servidor y cualquier tarea cuyo resultado llegue después. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Modela estados explícitos, conserva AbortController y prueba respuesta vacía, fallo, desconexión y carrera. El error que más veremos es este: mostrar spinner para siempre, tratar [] como error, permitir que una respuesta vieja pise una nueva o actualizar tras desconexión.

Lleva el modelo a un buscador con carga, vacío, error y carreras controladas. Si te atascas, vuelve al flujo de cuatro pasos; las pistas orientan la investigación, pero no entregan el programa.
