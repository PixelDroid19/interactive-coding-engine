Distingue una etiqueta reutilizable de HTML repetido y registra un custom element con un nombre válido. En esta clase construiremos una insignia de estado reutilizable; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

La etiqueta es una toma pública y el registro conecta esa toma con la clase que conoce el comportamiento.

Vamos con una aplicación distinta antes del reto. En una insignia de estado reutilizable, sigue la entrada, el cambio y la salida; después señala dónde aparecen Custom element y Registro.

Úsalo cuando una pieza tenga nombre de dominio, se repita y necesite un contrato que funcione desde HTML normal. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Elige nombres con guion, específicos y estables; registra una vez y conserva pequeño el contrato público. El error que más veremos es este: usar un nombre sin guion, registrar dos veces o convertir cada div pequeño en un componente.

Ahora cambia el contexto: construye una insignia de estado reutilizable. Empieza por el contrato observable, resuelve una decisión cada vez y prueba una variante antes de Comprobar.
