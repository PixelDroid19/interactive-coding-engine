Define CSS encapsulado y una API de tema pequeña mediante :host y custom properties. En esta clase construiremos una tarjeta tematizable sin romper encapsulación; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

El tema es una perilla pública, no una ventana a todos los selectores internos.

Vamos con una aplicación distinta antes del reto. En una tarjeta tematizable sin romper encapsulación, sigue la entrada, el cambio y la salida; después señala dónde aparecen static styles y CSS custom property.

Expón custom properties para decisiones de valor —color, espacio, tamaño— que consumidores realmente necesiten ajustar. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Ofrece fallbacks, conserva contraste y evita convertir cada regla CSS en API. El error que más veremos es este: estilos dentro de render, variables sin fallback, nombres genéricos que colisionan o temas que rompen accesibilidad.

Ahora cambia el contexto: construye una tarjeta tematizable sin romper encapsulación. Empieza por el contrato observable, resuelve una decisión cada vez y prueba una variante antes de Comprobar.
