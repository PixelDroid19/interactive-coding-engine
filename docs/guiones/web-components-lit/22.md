Sobrescribe callbacks nativos de LitElement sin cortar la maquinaria reactiva heredada. En esta clase construiremos un monitor que se conecta y limpia correctamente; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

Tu clase añade una estación a una línea existente. super permite que el tren de Lit siga recorriendo sus estaciones antes o después de tu trabajo.

Antes de ejecutar, haz una apuesta: ¿qué debería ocurrir en un monitor que se conecta y limpia correctamente y por qué? Usa Ciclo heredado y super.callback() para justificar tu predicción.

Sobrescribe callbacks nativos solo para recursos ligados a conexión; no los uses para observar cualquier propiedad. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Llama super, conserva simetría de recursos y evita repetir listeners internos declarativos que Lit ya gestiona. El error que más veremos es este: omitir super.connectedCallback y perder el primer update, limpiar con otra referencia o usar ciclo nativo para cálculos reactivos.

Es tu turno con un monitor que se conecta y limpia correctamente. Haz primero el camino mínimo completo, compruébalo en el navegador y después añade el caso alternativo.
