Prueba el componente como lo usa una aplicación: etiqueta, propiedades, eventos, accesibilidad y ciclos reales de navegador. En esta clase construiremos un diálogo reutilizable probado desde su API pública; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

Una prueba pública entra por la puerta del componente y observa sus salidas; si necesita desmontar paredes, el contrato está incompleto o la prueba está acoplada.

Antes de ejecutar, haz una apuesta: ¿qué debería ocurrir en un diálogo reutilizable probado desde su API pública y por qué? Usa Prueba de componente y Contrato publicable para justificar tu predicción.

Prueba en navegador todo componente que dependa de DOM, Shadow DOM, foco, eventos o ciclo de vida. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Comprueba resultados, no métodos privados; incluye teclado, estados, reconexión y más de una entrada. El error que más veremos es este: testear innerHTML exacto, llamar métodos privados, simular HTMLElement en Node o publicar sin documentar eventos y CSS hooks.

Es tu turno con un diálogo reutilizable probado desde su API pública. Haz primero el camino mínimo completo, compruébalo en el navegador y después añade el caso alternativo.
