Declara propiedades públicas en JavaScript, entiende conversión de atributos y diseña opciones sin decoradores. En esta clase construiremos una ficha configurable desde HTML y JavaScript; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

Lit instala sensores en propiedades declaradas: al cambiar una referencia, programa una actualización y render vuelve a describir la vista.

No leas el ejemplo como una receta. Pausa en cada paso de una ficha configurable desde HTML y JavaScript y predice qué observará el navegador antes de continuar.

Declara como pública la entrada que el consumidor debe controlar; no publiques detalles internos solo para hacerlos reactivos. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Usa tipos simples para atributos, defaults en constructor y nombres de atributo estables. El error que más veremos es este: usar campos de clase que ocultan accessors, reflejar sin necesidad o tratar objetos como atributos strings.

Te toca tomar las decisiones en una ficha configurable desde HTML y JavaScript. El starter prepara el escenario, pero la regla central sigue abierta; usa la vista previa como evidencia.
