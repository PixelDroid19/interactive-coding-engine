Selecciona directivas por identidad y claridad en vez de añadirlas por costumbre. En esta clase construiremos una bandeja de pedidos con identidad estable; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

repeat entrega una cédula estable a cada fila; cuando cambia el orden, Lit reconoce quién se movió en vez de confundirlo con su posición.

La demostración cambia de contexto a propósito. Recorre una bandeja de pedidos con identidad estable desde su contrato público hasta el DOM y pregunta qué sabe cada pieza.

Usa repeat cuando la lista cambia de orden, inserta o elimina y el DOM de cada fila tiene identidad; map basta para listas simples. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Elige claves únicas y duraderas; usa directivas solo cuando expresan mejor la intención que JavaScript normal. El error que más veremos es este: índice como clave, claves duplicadas, choose para dos ramas simples o directivas que ocultan una regla de negocio.

Cierra la explicación y trabaja desde el comportamiento esperado. Para completar una bandeja de pedidos con identidad estable, predice, implementa y comprueba más de una entrada.
