Aplica clases, estilos y referencias DOM con directivas específicas sin volver imperativo todo el componente. En esta clase construiremos una tabla interactiva con estado visual y foco; la meta no es memorizar una API, sino poder predecir el contrato antes de escribir código.

Las directivas son adaptadores estrechos: expresan una operación DOM concreta sin abandonar el flujo declarativo del template.

Ahora pondremos el modelo bajo presión con una tabla interactiva con estado visual y foco. Primero identifica los datos; luego el ciclo que actúa sobre ellos; al final comprueba la interfaz.

Usa classMap/styleMap con mapas dinámicos y ref para foco, medición o bibliotecas imperativas; no para leer datos que ya están en estado. Si el problema no necesita esa frontera, una función o HTML normal puede ser una decisión más sencilla.

Mantén mapas pequeños, valores CSS controlados y acceso DOM encapsulado en métodos con nombre. El error que más veremos es este: styleMap con datos no validados, ref como sustituto de estado o classMap para una sola clase ternaria.
