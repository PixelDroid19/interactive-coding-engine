Una expresión toma valores y produce otro. Antes de escribirla, nombra el tipo de entrada y el tipo de salida. Esa pregunta evita muchos resultados sorprendentes.

El signo más suma números, pero concatena si participa texto. Por eso convertimos de forma explícita con Number cuando recibimos dígitos escritos. Para comparar usamos triple igual y evitamos conversiones ocultas.

En el ejemplo cantidad llega como texto. Number produce el número tres; después la multiplicación produce doce. La comparación estricta confirma que el resultado es un número con valor doce.

Tu reto recibe otro texto numérico. Convierte primero y calcula después. Prueba también un dato distinto para asegurarte de que no escribiste la respuesta fija.
