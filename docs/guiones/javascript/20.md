fetch no significa “traer JSON”. Primero realiza una petición y devuelve una Response. Después decidimos cómo interpretar su cuerpo.

Una respuesta HTTP con error como 404 puede cumplir la promesa. Por eso comprobamos response.ok y lanzamos o devolvemos un error antes de llamar response.json().

El ejemplo separa tres pasos: pedir, validar y analizar. Esa secuencia hace visible dónde puede fallar.

Tu reto construye una función de validación para Response. No depende de internet; las pruebas entregan respuestas simuladas con estados distintos.
