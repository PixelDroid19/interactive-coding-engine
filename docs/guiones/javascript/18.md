JavaScript ejecuta una tarea a la vez, pero el navegador puede encargarse de temporizadores, red y eventos. Cuando terminan, sus callbacks esperan un turno.

setTimeout no pausa el archivo. Programa una función y la ejecución continúa. Incluso con cero milisegundos, la callback no interrumpe el código actual.

El ejemplo muestra primero inicio, después fin y por último tarea. La predicción nace del modelo, no de la velocidad del equipo.

Tu reto debe programar una callback sin bloquear. Las comprobaciones observan que la función se entrega al temporizador y que el código sigue siendo legible.
