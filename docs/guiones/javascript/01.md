JavaScript no adivina lo que quieres decir. Lee símbolos concretos, forma una instrucción y la ejecuta. Hoy no construiremos una página compleja: primero aprenderemos a producir una salida que podamos comprobar.

En console.log, console es la herramienta y log es una operación de esa herramienta. Los paréntesis contienen el valor que queremos mostrar. El texto va entre comillas porque, sin ellas, JavaScript buscaría un nombre.

Mira el archivo de arriba abajo. La primera llamada muestra “Inicio” y la segunda muestra “Listo”. Si intercambiamos las líneas, también cambia la salida. La consola nos deja verificar esa predicción.

Ahora escribe dos mensajes tuyos. Conserva la forma completa de cada llamada y comprueba que aparecen en el mismo orden. El reto evalúa la salida, no una frase de código memorizada.
