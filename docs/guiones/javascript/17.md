Los objetos de JavaScript viven durante la ejecución. Para guardar o transportar datos necesitamos una representación de texto. JSON cumple ese papel para valores compatibles.

JSON.stringify serializa; JSON.parse reconstruye una copia. localStorage solo guarda strings, por eso las dos operaciones suelen aparecer juntas.

El ejemplo convierte una preferencia, la guarda y después la recupera. El objeto leído no es la misma referencia del original.

Tu reto trabaja con funciones de serialización para que las pruebas sean seguras. Después podrás conectar ese contrato a localStorage sin mezclar almacenamiento con reglas.
