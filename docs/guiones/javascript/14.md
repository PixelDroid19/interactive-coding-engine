Una interfaz responde cuando ocurre algo. El navegador emite eventos y nosotros registramos una función para reaccionar.

addEventListener recibe el nombre del evento y la función manejadora. Entregamos la función sin paréntesis; si la llamamos, se ejecuta durante el registro.

El ejemplo espera el clic, lee el valor del input en ese momento y actualiza la salida. Leer antes guardaría una versión vieja.

En tu reto el botón debe incrementar un contador. El estado vive en JavaScript y la vista se actualiza después de cada cambio.
