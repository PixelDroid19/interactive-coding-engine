Una clase es útil cuando muchos objetos comparten comportamiento y cada uno conserva su propio estado. No es obligatoria para organizar cualquier función.

constructor recibe datos al crear una instancia. Los métodos se comparten mediante el prototipo; las propiedades como this.nombre pertenecen a cada objeto.

El ejemplo crea dos contadores independientes. Ambos comparten incrementar, pero cambiar uno no cambia el valor del otro.

Tu reto crea productos mediante una clase y una función fábrica pequeña para que podamos validar instancias con datos distintos.
