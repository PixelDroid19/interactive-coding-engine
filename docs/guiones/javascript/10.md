Los métodos de arrays no son palabras mágicas. Cada uno responde una necesidad distinta. Antes de elegir, describe la forma del resultado.

map produce una lista con una salida por elemento. filter conserva algunos. find devuelve el primer elemento que cumple. forEach ejecuta un efecto y no construye una lista útil.

El ejemplo transforma precios con map. La callback recibe cada precio y devuelve su doble. El array original permanece igual.

Tu reto debe filtrar. La salida necesita varios valores originales que cumplan una condición; eso descarta map y find.
