Depurar no es cambiar líneas hasta que desaparezca el mensaje. Es un ciclo de evidencia: reproducir, escribir esperado y observado, localizar la primera diferencia, formular una hipótesis y comprobar.

Un error de sintaxis impide interpretar. Uno de ejecución aparece al usar algo inválido. Uno lógico termina, pero entrega el resultado equivocado.

El ejemplo de total produce siete cuando esperamos doce. Los argumentos son correctos; la primera diferencia está en la operación. Cambiar suma por multiplicación confirma la hipótesis con otro caso.

Tu reto tiene un fallo distinto. No escribas el resultado fijo. Usa las comprobaciones para demostrar que la regla funciona con más de una entrada.
