Un array responde “en qué posición”. Un objeto responde “con qué nombre”. Sirve para reunir datos que describen una misma entidad.

Cada propiedad tiene clave y valor. El punto lee una clave conocida. Los corchetes permiten usar una clave que llega como dato. Una función guardada como propiedad se llama método.

El libro del ejemplo tiene título, páginas y una función resumen. this representa el objeto receptor durante esa llamada.

Tu reto no necesita métodos todavía. Recibe un objeto producto y produce un texto leyendo sus propiedades; pruébalo con productos distintos.
