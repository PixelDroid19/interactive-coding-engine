Hasta ahora observamos datos en la consola. El navegador también representa el HTML como un árbol de objetos llamado DOM.

getElementById busca un elemento por su id. querySelector usa un selector CSS. Ambos pueden no encontrar nada, así que el HTML y el selector deben coincidir.

El ejemplo encuentra salida y cambia textContent. La variable guarda la referencia al elemento; el texto nuevo aparece en la vista previa.

En tu reto el elemento ya existe. No crees HTML nuevo. Selecciónalo y escribe un mensaje que use la variable nombre.
