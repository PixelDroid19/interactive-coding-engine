Una función empaqueta una tarea con nombre. Su firma actúa como contrato: dice qué datos necesita y la llamada entrega argumentos concretos.

Los parámetros son nombres locales. return devuelve el resultado a quien llamó y termina esa ejecución. console.log solo muestra; no sustituye el valor devuelto.

areaRectangulo recibe ancho y alto. La función no conoce el ejemplo cinco por tres: aplica la misma regla a cualquier par válido.

En tu reto escribe una función pura. Primero prueba el cálculo con papel. Después usa dos entradas distintas para confirmar que ambos parámetros participan.
