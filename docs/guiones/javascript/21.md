Separar archivos no crea arquitectura por sí solo. Un módulo sirve cuando tiene una responsabilidad clara y expone un contrato pequeño.

export publica una capacidad. import la consume. Las reglas puras no deberían importar document; la interfaz puede importar reglas y decidir cuándo mostrarlas.

El ejemplo coloca calcularTotal en reglas y la interfaz lo usa. La flecha va desde main hacia reglas, no en ambos sentidos.

Tu reto escribe una exportación nombrada. La práctica posterior revisa responsabilidades, no una cantidad arbitraria de archivos.
