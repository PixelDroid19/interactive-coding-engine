Un método es una función que se llama desde un receptor. En texto.trim(), el texto aparece antes del punto y trim es la operación disponible para ese valor.

Para aprender un método no memorices una lista. Pregunta qué recibe, qué devuelve y si modifica el original. Los strings son inmutables: sus métodos producen un texto nuevo.

El ejemplo limpia espacios, convierte a minúsculas y después pregunta si comienza con una palabra. Cada retorno alimenta la siguiente llamada.

En tu reto aplicarás startsWith, que acabamos de usar. La función debe aceptar variaciones de mayúsculas y espacios sin cambiar el argumento original.
