Un Web Component une una etiqueta personalizada con una clase. Lo estudiaremos ahora porque ya conocemos DOM, eventos, módulos y clases.

La clase extiende HTMLElement. connectedCallback se ejecuta al conectarse. customElements.define registra un nombre con guion. Sin registro, el navegador solo ve una etiqueta desconocida.

Shadow DOM añade una frontera para estructura y estilos internos. No lo uses por decoración: úsalo cuando el componente necesita encapsulación y un contrato público.

Tu reto define un componente mínimo. La práctica revisa las tres piezas del contrato y evita entregar una solución completa en la plantilla.
