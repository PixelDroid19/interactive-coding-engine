Cuando varios valores forman una misma colección, crear una variable por cada uno deja de escalar. Un array los reúne y conserva su orden.

Las posiciones empiezan en cero. length indica cuántos elementos existen. push añade al final y modifica la lista; pop elimina el último. Antes de llamar un método pregunta si muta.

En el ejemplo, la segunda tarea vive en el índice uno. push agrega una tercera y length cambia. Seguimos la lista antes y después para hacer visible el efecto.

Tu reto recibe un array. No supongas su tamaño. Usa la posición y length para producir el resultado solicitado con listas distintas.
