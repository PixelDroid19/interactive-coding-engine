Un paradigma es una forma de organizar el código. En JavaScript vas a ver dos todo el tiempo. Objetos con datos y acciones juntos. Y funciones que transforman datos sin revolver el original. No son religiones. Son herramientas.

En la orientada a objetos agrupas datos y acciones en una cosa. Una cuenta tiene saldo. Puede depositar y retirar. El saldo no se toca desde afuera a lo loco. Se toca con métodos.

Sirve cuando hay una cosa que hace cosas y dura en el tiempo. Un jugador. Un carrito. Un componente.

En el estilo funcional prefieres funciones que reciben datos y devuelven datos nuevos. No cambian el original si pueden evitarlo. map y filter viven aquí. Sirve cuando transformas listas. De esta lista de precios, saca los que superan cien.

JavaScript te deja mezclar. No elijas bando. Elige según el problema. Si el estado vive y cambia, un objeto ayuda. Si es entra lista, sale lista, una función se lee mejor.

Con esto cierra el curso de fundamentos. Ya puedes guardar datos, decidir, repetir, agrupar, y hablar de si tu solución escala. El siguiente paso es usar esto en páginas de verdad.
